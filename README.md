# Pl3xMapMarker

Плагин для **Paper** серверов, который добавляет возможность ставить **метки** и **прямоугольные территории** на карту [Pl3xMap](https://modrinth.com/plugin/pl3xmap).

Игроки могут отмечать интересные места и свои территории прямо из игры — всё отображается на веб-карте в реальном времени.

---

## Возможности

- **Метки (Marker)** — иконка-пин в точке, где стоит игрок
- **Территории (Territory)** — прямоугольные области с настраиваемым цветом
- Лимиты на количество объектов на игрока
- Кулдауны на создание и удаление
- Права: обычные игроки могут управлять только своими объектами, админы — всеми
- Автоматическое сохранение в `markers.yml`
- Встроенная красная иконка-пин (генерируется плагином)

---

## Требования

| Компонент     | Версия                          |
|---------------|---------------------------------|
| Minecraft     | 1.21.11+ (API 26.1.2)           |
| Сервер        | Paper (или форки на его базе)   |
| Pl3xMap       | 26.1.2-549+                     |
| Java          | 25+                             |

Плагин **обязательно** зависит от Pl3xMap (`depend: [Pl3xMap]`).

---

## Установка

1. Установи [Pl3xMap](https://modrinth.com/plugin/pl3xmap)
2. Скачай `Pl3xMapMarker-1.0.jar` из [Releases](https://github.com/svvova/Pl3xMapMarker/releases) (или собери сам)
3. Положи jar в папку `plugins`
4. Перезапусти сервер
5. Настрой `plugins/Pl3xMapMarker/config.yml` при необходимости

---

## Команды

Основная команда: **`/mapmark`**

| Команда | Описание | Право |
|---------|----------|-------|
| `/mapmark marker <текст>` | Поставить метку в текущей позиции | `mapmark.marker` |
| `/mapmark pos1` | Установить первую точку территории | `mapmark.territory` |
| `/mapmark pos2` | Установить вторую точку территории | `mapmark.territory` |
| `/mapmark territory <текст> [#цвет]` | Создать прямоугольную территорию | `mapmark.territory` |
| `/mapmark list [ник]` | Список объектов (своих или указанного игрока) | `mapmark.marker` / `mapmark.territory` / `mapmark.admin` |
| `/mapmark delete <id>` | Удалить объект по ID | владелец или `mapmark.admin` |
